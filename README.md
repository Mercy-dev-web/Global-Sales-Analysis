# Global Sales Analysis

An independent data analysis project exploring global sales performance using Microsoft Excel and a sample sales dataset.

> **Project status:** In progress. Dashboard screenshots and final validation of the reported metrics will be added before the project is marked complete.

## Project Overview

This project examines sales performance across regions, countries, product categories, sales channels, and customer segments. The goal is to turn transaction-level data into useful business insights that can support better commercial decisions.

The Excel workbook contains four dashboard views:

- **Sales:** overall sales performance and regional/channel trends
- **Products:** product and category performance
- **Demography:** geographic sales distribution
- **Customers:** customer and segment analysis

## Tools Used

- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas and calculated metrics
- Interactive dashboard filters (where included in the workbook)

## Dataset

The project uses a **sample dataset** for learning and portfolio demonstration. It is not confidential company data and should not be interpreted as the actual performance of a named organization.

The dataset covers:

- 3,000 sales transactions
- 16 countries
- 4 sales regions
- 2024–2025

## Key Insights

Initial analysis suggests:

- North America recorded the highest revenue among the four regions.
- Electronics was the highest-revenue product category.
- Online sales generated the highest revenue among the sales channels.
- Argentina recorded the highest revenue among the countries in the dataset.
- The Consumer segment contributed the highest revenue among customer segments.

These observations will be refined and supported with dashboard visuals during the final review.
